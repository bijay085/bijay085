## Chrome Extensions

Three tools on the Chrome Web Store. Free. Built because I needed them for SEO work.

<a href="https://chromewebstore.google.com/detail/seo-checker/kkkmgadddcabjfccbknmalbhiecfheog"><img src="https://img.shields.io/badge/Add_to_Chrome-2563EB?style=flat-square&logo=googlechrome&logoColor=white" alt="Install SEO Checker"></a>

On-page SEO · Search Console

### InfoFill

<a href="https://chromewebstore.google.com/detail/infofill/pahmcohlbodgpmagnneghackbogangdc"><img src="https://img.shields.io/badge/Add_to_Chrome-2563EB?style=flat-square&logo=googlechrome&logoColor=white" alt="Install InfoFill"></a>

Autofill · Outreach

### SERP Sheet

<a href="https://chromewebstore.google.com/detail/serp-sheet/loomginndkpobojjpgigmgchdoehepem"><img src="https://img.shields.io/badge/Add_to_Chrome-2563EB?style=flat-square&logo=googlechrome&logoColor=white" alt="Install SERP Sheet"></a>

**Google results straight into a spreadsheet**: positions, titles, URLs, snippets. Rank tracking and competitor research without a paid SERP API. Search, click, export.

SERP scraping · Rank tracking
